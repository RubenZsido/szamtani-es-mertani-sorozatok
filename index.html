Számtani sorozat

Számtani a sorozat, ha minden tag ugyanannyival nagyobb (vagy kisebb), mint az előző. Ezt a lépést differenciának hívjuk, jele \(d\).

Képletek

  • Mennyi a differencia? Mik a következő tagok?

    \(d = a_{k+1} - a_k\), utána add hozzá \(d\)-t.

  • Mennyi az n. tag?

    \[ a_n = a_1 + (n-1)d \]

  • Hányadik tagja a sorozatnak a …?

    Oldd meg: \(a_1 + (n-1)d = \text{adott érték}\) → \(n\) egész.

  • Mennyi az első tag?

    \(a_1 = a_n - (n-1)d\)

  • Add meg \(a_1\)-et és \(d\)-t (két ismert tag).

    \(d = \dfrac{a_m - a_k}{m-k}\), \(a_1 = a_k - (k-1)d\)

  • Mennyi az első n tag összege?

    \[ S_n = \frac{n}{2}\bigl(2a_1 + (n-1)d\bigr) = \frac{n}{2}(a_1 + a_n) \]

1. Felismerés

Példa

A 2, 5, 8, 11, … sorozat számtani, mert \(5-2 = 8-5 = 11-8 = 3\). Tehát \(d = 3\). A következő tag: \(11 + 3 = 14\).

2. Következő tag — először számoljunk végig

Példa

\(a_1 = 2\), \(d = 3\). Az 5. tagot még kézzel is kiírhatod:

2, 5, 8, 11, 14. Négy lépés kellett az ötödik tagig: \(2 + 4\cdot 3 = 14\).

3. A képlet nagyobb n-re

Példa

\(a_1 = 3\), \(d = 2\). A 15. tag: \(a_{15} = 3 + 14\cdot 2 = 31\).

Negatív differencia is lehet: akkor a sorozat csökken.

4. Hányadik tag?

Példa

\(a_1 = 4\), \(d = 5\). Melyik tag a 49?

  1. \(4 + (n-1)\cdot 5 = 49\)
  2. \((n-1)\cdot 5 = 45\)
  3. \(n-1 = 9\), tehát \(n = 10\).

5. Az első tag visszafelé

Példa

A 8. tag 20, \(d = 3\). Akkor \(20 = a_1 + 7\cdot 3\), tehát \(a_1 = 20 - 21 = -1\).

6. Két ismert tag

Példa

\(a_3 = 10\), \(a_7 = 22\). A két index között 4 lépés van:

  1. \(d = (22-10)/4 = 3\)
  2. \(a_1 = 10 - 2\cdot 3 = 4\)

Ellenőrzés: \(a_7 = 4 + 6\cdot 3 = 22\).

7. Az első n tag összege

Példa

\(a_1 = 2\), \(d = 3\), első 10 tag. \(a_{10} = 2 + 9\cdot 3 = 29\), így

\[ S_{10} = \frac{10}{2}(2 + 29) = 5\cdot 31 = 155. \]

8. Szöveges feladat

Példa

Hétfőn 10 percet futsz, minden nap 5 perccel többet, 7 napon át. \(a_1 = 10\), \(d = 5\), \(n = 7\):

\[ S_7 = \frac{7}{2}\bigl(20 + 6\cdot 5\bigr) = \frac{7}{2}\cdot 50 = 175 \text{ perc.} \]

9. Két tagösszeg

Példa

\(a_2 + a_3 = 16\) és \(a_4 + a_5 = 24\).

  1. \(2a_1 + 3d = 16\)
  2. \(2a_1 + 7d = 24\)
  3. Kivonva: \(4d = 8\), \(d = 2\), majd \(a_1 = 5\).
